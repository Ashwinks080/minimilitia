## 🔧 Customization Guide

### Add New Vehicle
Edit `game_world.py`, modify `Vehicle` class:
```python
elif vehicle_type == VehicleType.HUMMER:
    self.width = 70
    self.height = 40
    self.max_speed = 250
    # ...
```

### Add New Mission
Edit `mission_system.py`, add to `_generate_missions()`:
```python
("M9", "New Mission", MissionType.DELIVERY,
 "New mission description", 1000),
```

### Change Map Size
Edit `game.py`:
```python
game = GTAGame(width=2000, height=1200)  # Bigger map
```

### Adjust Difficulty
Edit `mission_system.py`:
```python
self.time_limit = 180  # Reduce time from 300 seconds
self.reward_money = 2000  # Increase rewards
```
